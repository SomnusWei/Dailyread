# 教材知识体系图谱（供 SKILL.md 引用）

《石学敏针灸全集 第2版》全书 1071 页结构（页码为 PDF 书签页）：

## 绪言 石学敏院士学术思想（p22-29）
七大创新主线：①破译"是动/所生"内涵 ②醒脑开窍针刺法 ③针刺手法量学 ④针灸抗衰老（SAM小鼠/调神益智平肝通络）⑤刺络疗法（加压拔罐）⑥中医急症医学 ⑦疑难病特效针法 + 五专模式

## 第一部分 针灸理论（p30-351）
- 第一章 经络总论（p32）：经络系统组成（十二经脉为主体+奇经八脉+十五络脉+经别/经筋/皮部）、生理病理、诊断治疗应用
- 第二章 腧穴总论（p39）：腧穴分类与作用；**主治六大规律**（腧穴所在主治所能/经脉所过主治所及/特定腧穴特定主治/同一腧穴双向主治/主治相同疗效有别/主治要领）；特定穴（五输、原、络、郄、俞募、交会、八会、八脉交会）
- 第三章 经络各论（p49）：十二正经+奇经八脉逐经循行
- 第四章 腧穴各论（p90）：逐经腧穴定位主治（p90-283，含常用奇穴）
- 第五章 刺灸法（p284）：
  - 《内经》针法（补泻原则、刺法、得气、宜忌）
  - 《难经》针法（双手行针、营卫补泻、迎随调气）
  - 《金针赋》针法（下针十四法、飞经走气四法、治病八法）
  - 《针灸大成》针法（十二字手法、下手八法、补泻"量"的论述）
  - 现代针刺手法（毫针/头针/耳针/电针/芒针/火针/皮肤针/皮内针/三棱针/腕踝针/穴位注射）
  - **第六节 石氏针刺手法（p330，全书技术核心）**：针刺手法量学、刺络拔罐疗法、经筋刺法、针刺治神
  - 灸法（p347）：操作、具体灸法、禁忌

## 第二部分 《灵枢·经脉》篇病候与临床（p352-393）
第六章 十二经病候：总论（历代"是动/所生"论述→石学敏概念新解→传变规律→六厥证探讨）+ 十二经逐条（是动病/所生病/虚实辨证），每经对应治疗大法与处方

## 第三部分 常见病针灸治疗（p394-643）
- 第七章 治疗总论（p396）：
  - 治疗原则：**治神守气（首位）**、清热温寒、补虚泻实、整体观念、治病求本、三因制宜
  - 治疗作用：醒神开窍（列第一）、疏通经络、扶正祛邪、调和阴阳
  - 配穴处方：近部/远部/辨证对症选穴 + 本经/表里经/同名经/上下/前后/左右配穴
  - 特定穴应用：五输（"井主心下满，荥主身热，输主体重节痛，经主喘咳寒热，合主气逆而泄"；虚则补其母实则泻其子）、原络主客配穴、俞募（以阴引阳以阳引阴）、八脉交会（公孙-冲脉、内关-阴维…八穴歌）、八会、下合、郄穴
  - **第五节 醒脑开窍法（p410-441，全书临床核心）**：中医"神"论→辨病与辨证观→"窍闭神匿"中风总病机→针法组成（大/小醒脑）→临床应用（中风各期+合并症+"失神"病证扩展）→基础研究
- 第八章 治疗各论（p441-643）：内、骨伤风湿免疫、妇、男、儿、皮肤、外、五官、精神科等 100+ 病种的辨证治则/选穴/操作/加减

## 第四部分 临床医案（p644-1066）
第九章内科（脑卒中及合并症、面瘫、郁证、痹证、痿证、大动脉炎、痴呆等，p646-897）→ 骨伤风湿 → 妇科 → 男科 → 儿科 → 皮肤 → 外科 → 五官科 → 精神科 → 急症 → 其他
医案固定体例：主诉/病史/查体/中医诊断/西医诊断/辨证/治则/选穴/操作（含量学参数）/治疗经过，部分附治疗前后脑血流图或CT影像
