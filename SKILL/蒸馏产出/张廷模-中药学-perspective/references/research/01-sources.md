### S1 素材性质说明（课堂层）
- 张廷模本人课堂讲授实录（第一人称"我"、称呼学生"同学们"），非他人转述、非教材正文。
- 覆盖《中药学》全课程：绪言、中药学发展史、品种产地采集贮存、炮制、性能（四气/五味/归经/升降浮沉/毒性）、配伍、禁忌、用法，以及各论 79 讲全部药物。
- 讲授以本人主编教材（高等教育出版社2002年"面向21世纪课程教材"《中药学》）为蓝本，故教材编写决策与讲授内容可互证。

### S2 素材性质说明（专著层）
- 版本信息：人民卫生出版社 2013 年 5 月第 1 版，ISBN 978-7-117-17020-8，551 千字，定价 52.00 元。
- 项目背景：**国家重点基础研究发展计划（973计划）项目"中医理论体系框架结构研究"（2013CB532000）之课题五"中药方剂理论框架结构研究"（2013CB532005）研究成果**。
- 缘起（本人自述）："上世纪80年代笔者即在一些中医药重要期刊上撰文阐述了这一思想……如《论中药'功效'论述的不完整性》（1987）"——即本书是三十余年研究的系统化。
- 载体：读秀/SuperStar 数字化扫描本，无文本层，需 OCR（本次以 rapidocr 200dpi 全页识别，463/464 页有识别结果）。
- 结构（13章，见 `04-knowledge-map.md`）：功效的含义与分类 → 功效认识的发展史 → 功效记述的不完整性 → 功效认识的特殊性与局限性 → 认定与记述原则 → 术语规范的必要性与方法（含"六性"）→ 术语应用现状调查与规范化方案 → 术语规范化举隅（14节）→ 易生歧义术语建议 → 常见药物功效规范化论证（25节）→ 规范化表述建议（逐药）→ 应予思考的问题。
- 本素材的独特价值：**它是 S1 课堂中所有"功效删改"决策的理论论证版**——课堂讲结论，专著给论证。

## 三、跨素材交叉验证（本次已执行）

两层素材可交叉验证，结论如下（详见 `02-extraction-notes.md` 的"交叉验证"一节）：

**A. 互证（★）——讲稿的核心信念在专著中有系统论证**

| 讲稿观点 | 专著对应 |
|---------|---------|
| 功效必须是直接作用，"隔二隔三"不算功效 | 第一章 + 第六章第四节；并给出黄宫绣《本草求真》原文与"源/流"判据 |
| 复方功效 ≠ 单味药功效 | 单立"方药离合"原则（引徐灵胎《医学源流论》、丹波元坚《药治通义》） |
| 功效是中药学的核心与生长点 | 绪言原句"功效内容必然是个活跃的生长点"（讲稿几乎照述） |
| 药性要从功效反推 | 第一章"功效既是总结性能的基础，又是确定主治的依据" |
| 十余处药物功效改动 | 第十一章逐条成节论证（麻黄/细辛/淡豆豉/大黄/厚朴/肉桂/吴茱萸/三七/花蕊石/人参等） |
| "在搞功效术语规范化，是国家课题" | 第八章给出具体机构、时间、人物与三步计划（2000年成立名词委、朱建平项目等） |

**B. 差异/演进（⚡）——两处立场不一致，如实保留不调和**

| 主题 | S1 课堂 | S2 专著 |
|------|--------|--------|
| 葛根"解肌" | 回避（"讲清楚要10分钟，反而引起混乱"） | 明确保留（"葛根在现代中药专著功效项中仍保留使用'解肌'这一术语"） |
| "消导"术语 | 考出汪昂后主张连"消导药"之名都不必保留 | 主张保留"消导"，限定为"消食、行气"并分列 |
| 百部/紫菀/款冬花"润肺" | 百部删；紫菀款冬花"保留可以，不保留也有道理"（两可） | 三者一律"不宜保留"，仅蜜炙条件下可言润肺 |
| 水牛角"定惊" | 删 | 改术语为"息风止痉"（真正该删"定惊"的是重楼、青黛） |
| 五味子归类失误 | 承认"先入为主就改不过来" | 未作自我检讨，仅指出教材"主次不分" |
| 药性程度定量 | "温到什么程度叫热……谁也讲不清楚" | 未正面讨论；只讨论功效记述的相对性与剂量相关性 |

## 五、素材形态的局限（重要）

- **S1（教学型）**：个人经历类内容相对稀薄；"栽过的跟头"以"纠正教材/前人之误"为主，密度低于访谈类素材。
- **S2（OCR 扫描本）**：存在断行与个别字词缺损（已在校验中标注可疑处，如 L13124、L13419、L22857、L24201"土茯苓"条疑有笔误/OCR 误），引用处的字词以上下文可辨识为准，未作补字。
- **S2（体例）**：第三章（L1009–12440，占全书约148页）为"本草纲目补虚功效术语 + 历版教材功效对比表"的资料汇编，**理论论述仅占不足 2%**（集中在 L1013–1148 与 L12434–12438），提取时已明确跳过资料条目；第八章（L14132–17642）的第二节"调查报告（一）（二）"亦以明细数据为主。
- **覆盖完整性**：S1 为完整 79 讲；S2 为完整 13 章（OCR 覆盖 463/464 页）。
