# 病案分析框架

> 供「病案分析」功能使用。输入病案后按本框架逐层推进，输出结构化分析报告。

---

## 一、标准工作流程（六步法）

```
病案输入 → ①四诊信息提取 → ②辨证分析 → ③病因病机推演 → ④治法确立 → ⑤方药拟定 → ⑥经典文献对照
```

### 第 1 步：四诊信息提取（结构化表格）

| 四诊 | 提取要点 | 病案中的信息 |
|------|---------|------------|
| **望诊** | 神色、形态、舌质、舌苔、排泄物 | … |
| **闻诊** | 声音、气味 | … |
| **问诊** | 主诉、现病史、寒热、汗、头身、二便、饮食口味、睡眠、经带 | … |
| **切诊** | 脉象（寸关尺、浮沉迟数）、按诊（腹诊、肌肤） | … |

**规则：**
- 病案未记载的项目明确标注「未载」，不得臆造
- 优先标记**具有辨证决定意义**的信息（如舌红苔黄腻→湿热）
- 十问歌逐项核对：一问寒热二问汗，三问头身四问便……

### 第 2 步：辨证分析（八纲 + 脏腑 + 病性）

1. **八纲定位**：表里、寒热、虚实、阴阳
2. **病位**：脏腑经络定位（结合五行生克、脏腑关联）
3. **病性**：六淫、痰饮、瘀血、气滞、食积、虚实夹杂
4. **辨证结论**：使用标准格式——

```
**辨证：{证型名}（{病机概述}）**
病位：{脏腑/经络}
病性：{虚实寒热}
```

### 第 3 步：病因病机推演

用箭头图呈现病机演变链条：

```
{病因} → {第一层病机} → {第二层病机} → {当前主症病机}
                    ↘ {兼夹病机} → {兼症}
```

### 第 4 步：治法确立

- **总治则**：正治反治、标本缓急、扶正祛邪、调整阴阳
- **具体治法**：与证型一一对应（如「肝郁脾虚→疏肝健脾」）

### 第 5 步：方药拟定

- **主方**：首选经方/时方，注明出处
- **方义分析**：君臣佐使逐味拆解（见 prescription-guide.md）
- **加减**：针对兼症的具体加减法
- **调护**：饮食宜忌、起居建议

### 第 6 步：经典文献对照（本知识库特色）

用检索脚本查找经典依据，引用原文佐证辨证与选方：

```bash
python scripts/search_textbooks.py --keyword "{核心证候或方名}" --category 金匮要略,伤寒论
```

输出格式（条文卡片，借鉴经方派风格）：

> **【经典依据】**《金匮要略·胸痹心痛短气病脉证治》：「师曰：夫脉当取太过不及，阳微阴弦，即胸痹而痛，所以然者，责其极虚也。」

## 二、疑难病案的处理规则

| 情形 | 处理方式 |
|------|---------|
| 四诊信息不全 | 列出「需要补充的问诊清单」，按最可能证型给出试探性分析 |
| 证候矛盾（寒热错杂） | 分清标本、先后、主次；考虑上热下寒（半夏泻心汤类）、表寒里饮（小青龙汤类）等格局 |
| 多证并存 | 主证定主方，兼证作加减；避免多方堆砌 |
| 久病虚实夹杂 | 遵循「久病及肾」「久病入络」思路，考虑扶正与祛邪比例 |
| 倪海厦经验参考 | 危重症先辨阴阳（阳气存亡），参附四逆辈当机立断 |

## 三、病案来源与练习模式

1. **用户提交病案**：按六步法完整分析
2. **知识库取案**：从医案医话类古籍（64 部）提取真实医案做示范分析
   ```bash
   python scripts/search_textbooks.py --keyword "{病名}医案" --category 医案医话
   ```
3. **教学出案**（配合模拟题功能）：从中医内科学教材提取病案，隐去治法方药作为练习题，附标准答案

## 四、输出质量标准

- 每一步都必须有**证据链**：结论 ← 四诊依据 ←（缺一不可）
- 辨证结论必须落到**标准证型名**（与中医诊断学教材一致）
- 经典引用必须注明**书名+篇名**，原文用引号
- 方药剂量给出**现代常用量**并注明「原方剂量另列」，毒性药物必须标注（见 SKILL.md 通用规则）
- 不确定处明确写「本案亦可从{X}证考虑，鉴别点在于{Y}」，禁止武断
