## 知识库检索（所有功能的基础）

### 检索脚本（必须使用，禁止凭记忆引原文）

```bash
cd {skill目录}/scripts

# 全库检索（跨 711 文件）
python search_textbooks.py --keyword "胸痹" --context 6 --max-hits 20

# 按类目过滤（支持: 伤寒论,金匮要略,本草,针灸推拿,医经,温病瘟疫,医案医话,方书,脉学诊法,妇产科,儿科）
python search_textbooks.py --keyword "栝蒌薤白" --category 金匮要略

# 指定文件精确检索
python search_textbooks.py --keyword "桂枝汤" --files "499-金匮要略方论.txt"

# 只看命中统计（快速定位素材最多的书）
python search_textbooks.py --keyword "小柴胡汤" --quiet
```

### 检索策略（重要）

1. **先现代教材定基线，再古籍补充深度**：概念/治法/方义以教材为准，经典原文与临床发挥查古籍
2. **关键词分层**：疾病名 → 证型名 → 方名 → 药名 → 理论术语，逐层缩小
3. **条文核对**：引用经典条文前必须用脚本核对原文，禁止凭记忆引用
4. **古籍文风适配**：古籍含「<篇名>」「<目录>」「属性：」等标记，脚本已自动清理为【篇】【目录】

### 素材批量提取（讲义/深度内容用）

```bash
# 按系统提取（8 大系统: 肺系/心系/脾胃系/肝胆系/肾系/脑系/气血津液/肢体经络）
python extract_content.py --system 肺系 --textbook-dir "F:/work/中医学skill/教材" --output-dir 讲义素材

# 深度模式 + 古籍经典文献
python extract_content.py --system 心系 --depth deep --ancient --category 伤寒论,金匮要略
```

输出自动分为 6 个模块：疾病概论、辨证论治、方剂详解、中药详解、基础理论、经典文献。

## 功能一：中医学习

**流程：** 定位主题 → 知识库检索 → 结构化讲解 →（可选）关联延伸

**讲解结构（按主题类型）：**

| 主题类型 | 讲解框架 | 主要检索源 |
|---------|---------|-----------|
| 基础理论（阴阳/五行/脏腑/气血津液） | 概念定义 → 脏腑功能 → 生理病理联系 → 临床意义 | 中医基础理论.txt + 医经类古籍 |
| 证候/辨证 | 概念 → 病因病机 → 临床表现 → 辨证要点 → 鉴别诊断 | 中医诊断学.txt |
| 疾病 | 定义 → 病因病机 → 证型分类 → 分证论治（表格）→ 转归预后 | 中医内科学.txt + 伤寒金匮 |
| 经典条文 | 原文 → 逐句释义 → 病机分析 → 方证 → 类证鉴别 | 伤寒论/金匮要略类古籍 |

**风格规则：**
- 结构化输出：表格 + 加粗重点 + 分层小标题
- 经方相关内容融入倪师思维：先阴阳大局、再抓主证、条文卡片佐证（见 prescription-guide.md 第 2 层）
- 概念解释配 1-2 个临床实例，实例优先从医案医话类古籍取材

## 功能二：讲义制作

继承 tcm-lecture-builder 六阶段流程：

```
① 需求确认 → ② 素材提取 → ③ 内容整合 → ④ 讲义生成(HTML) → ⑤ PDF导出 → ⑥ 质量检查
```

**① 需求确认：** 讲义主题（系统/疾病/方剂/经络……）、深度（基础/标准/深度）、篇幅、是否含针灸与古籍内容。

**② 素材提取：** 用 `extract_content.py` 批量提取（见上文检索策略），人工翻阅素材文件筛选。

**③ 内容整合：** 按理法方药体系组织——
- **理**（基础理论）→ **法**（治法治则）→ **方**（方剂详解）→ **药**（中药详解）
- 8 大系统关键词映射见 `references/keyword-mapping.md`

**④ 讲义生成：** 使用 `templates/lecture-template.html` + `templates/lecture-style.css`（理法方药四色块、表格系统、条文卡片样式已内置）。内容规范沿用：口语正文 + 表格 + 加粗重点；经方条文卡片一卡一方。

**⑤ PDF 导出：** Chrome 无头模式：
```bash
"C:/Program Files/Google/Chrome/Application/chrome.exe" --headless --disable-gpu \
  --print-to-pdf="输出.pdf" --no-pdf-header-footer "讲义.html"
```

**⑥ 质量检查：** 执行 `python scripts/validate_html.py`，并按 `references/quality-checklist.md` 的 P0/P1/P2 分级逐项核对（P0 项不过不交付）。

## 功能三：病案分析

**必读 `references/case-analysis.md` 后执行。** 核心为六步法：

四诊信息提取（表格，未载项标「未载」）→ 辨证分析（八纲+脏腑+病性，标准格式 `**辨证：{证型}（{病机}）**`）→ 病因病机推演（箭头链条图）→ 治法确立 → 方药拟定（君臣佐使+加减+调护）→ 经典文献对照（检索脚本查条文佐证）

**红线：** 不得臆造四诊信息；证型必须用标准名称；经典引用必须核对；不确定处写「本案亦可从 X 证考虑，鉴别点在于 Y」。

## 功能四：针灸

**主题路由：**

| 子主题 | 处理方式 | 检索源 |
|--------|---------|--------|
| 腧穴定位/主治 | 穴名 → 归经 → 定位（骨度分寸+解剖标志）→ 主治 → 配伍 → 操作 | 经络腧穴学.txt + 299-针灸大成.txt |
| 经络循行 | 十二正经/奇经八脉：循行路线 → 联系脏腑 → 主治病候 → 常用穴 | 经络腧穴学.txt + 医经类古籍 |
| 针灸治疗 | 辨证归经 → 处方（主穴+配穴+方义）→ 操作（补泻/留针/灸法） | 针灸治疗学.txt + 石学敏针灸全集.txt |
| 特定穴理论 | 五输穴/原穴/络穴/八会穴/八脉交会穴/下合穴/郄穴 | 经络腧穴学.txt |
| 刺法灸法 | 毫针/三棱针/皮肤针/艾灸/拔罐/电针的适应与禁忌 | 石学敏针灸全集.txt |

**腧穴讲解固定结构：**
```
{穴名}（{拼音}·{归经}·{特定穴属性}）
定位：{骨度分寸描述}＋{简易取穴法}
主治：{近治/远治/特殊主治 分类列}
操作：{直刺/斜刺深度、灸法、禁忌}
```

**经典腧穴歌赋**（针灸大成类）可用于记忆口诀：`python search_textbooks.py --keyword "百会" --category 针灸推拿 --quiet` 定位书籍后细读。

**安全规则：** 眼区（睛明承泣）、胸背（深刺防气胸）、延髓区（哑门风府）等危险部位穴位必须标注针刺深度与角度警示。

## 功能五：中药处方讲解

**必读 `references/prescription-guide.md` 后执行。** 核心为五层讲解：

方名释义 → 出处与经典条文（经方条文卡片必出）→ 组方结构（君臣佐使表）→ 逐味药讲解（性味归经+功效+本方作用）→ 临床运用（辨证眼目+加减+类方鉴别+禁忌）

**剂量规则：** 原方剂量与现代常用量双列（一两≈3g 教材通行）。**毒性药物（附子、细辛、半夏、乌头、甘遂、朱砂、马钱子等）必须加 ⚠️ 警示框**：剂量上限、煎法（先煎久煎）、十八反十九畏。

**单味药讲解**：药名 → 性味归经 → 功效主治 → 本草经典原文（检索本草类目）→ 配伍应用 → 用法用量 → 禁忌。

**倪师风格口述版**（用户要求时）：第一人称口语、抓主证先行、阴阳大局定位，正文口语 + 表格重点标注。

## 功能六：模拟题出题

**必读 `references/quiz-guide.md` 后执行。** 核心为四步流程：

确认需求（**大纲/题数/总分三项必问**，缺一不可；默认执业医师风格·10 题·100 分）→ 知识库取材（**题干与答案必须有出处**）→ 命题写入 exam.json（single/multiple/fill/short 四题型 schema，分值合计=总分）→ 用 `scripts/build_exam_html.py` 生成交付物

**标准交付物：**

```bash
python scripts/build_exam_html.py --exam exam.json --output-dir 试卷输出 --name "{试卷名}"
# 默认随机打乱选择题选项顺序，避免“正确答案位置集中（如几乎全为 A）”：
#   --no-shuffle  保留题库原选项顺序
#   --seed N      固定打乱种子，可复现某一次选项顺序
```

1. **交互式 HTML 试卷（必出）**——顶部填学生姓名；单选→单选框、多选→复选框、填空→输入框、简答→文本域；底部提交后**原地立即批改**：客观题自动判分（对错高亮）、主观题给参考答案+评分要点自评、成绩卡显示姓名/得分/正确率/总分，提交后锁定作答区
2. **答案卷 HTML（必出）**——每题附答案、解析、知识库出处；**PDF 不强制**，仅当用户明确要求 PDF/打印版时才转（本机 Chrome 失败则用 Edge，命令见 quiz-guide.md）

**PWA 学习中心部署（学习中心「📝 考试」模块，成绩自动关联账号 + 回显）**：
- **发布前置**：试卷与答案卷 HTML 成对上传（两者可含同一 `exam_id`，答案卷可不含）；服务器从考卷 HTML 提取 `exam_id` 建考试；**标题缺省自动取考卷文件名（去 `.html`）**。
- **账号关联（成绩归属）**：生成卷内置账号识别——优先 URL `?student=<username>`/`?u=`，其次读取同源 `localStorage['lc_user'].username`；识别后自动预填卷首姓名（学生可改）。学生提交时随上报 body 附带 **`student_username`** 字段，服务器归属优先级：`student_username`（卷显式上报）→ 学习中心会话 Cookie（`lc_token`）→ 卷内 `student_name`。**成绩因此精确计入学习中心账号，改名不影响归属。**
- **成绩回显（重开可见作答与批改）**：学生/教师在「考试」模块对已交卷点击「查看考卷」时，前端调 `GET /api/learning/exams-detail?exam=<exam_id>&user=<账号>` 取该生作答明细并写入同源 `localStorage['lc_exam_review:<exam_id>']`，再以 **`?r=1`** 打开试卷 → 卷内进入回显模式：还原该生勾选/填空/简答文本，整卷锁定（禁提交，顶部成绩卡显示姓名/得分/客观分/主观自评/提交时间），逐题批改标注（答对绿/答错红并展示正确答案与本人作答/未答标记/简答自评）。
- **上报协议**：body 顶层 `type:"exam_result"` + `exam_id` + `student_name` + `student_username`（识别到账号时）+ `total_score/final_score/objective_*/subjective_*` + `accuracy` + `answers[]`（`qid/type/max_score/score/answer/correct/self_score`）。服务器 `POST /api/exam/submit` 返回任意 2xx 即成功、重复提交返回 `{ok:true,ignored:true}`、未开始/已截止返回 400。完整字段与服务器最小实现见 `references/quiz-guide.md`「成绩自动上报」节。
- **无账号直开试卷**：不上报 `student_username` 亦不读取账号；服务器按 Cookie/姓名回退，不影响页面判分与本地留档。

质量自检（分值合计、难度分布 3:5:2、答案核对）通过后再交付。

## 通用规则（所有功能必须遵守）

1. **出处至上**：所有经典条文、方剂组成、腧穴主治引用前，先用检索脚本核对；禁止凭记忆引用原文
2. **编码注意**：现代教材 UTF-8、古籍 GB18030——直接读文件时必须使用 `scripts/text_utils.py` 的 `read_text()/read_text_lines()`，不得裸用 `open(encoding="utf-8")`
3. **毒性药物警示**：涉及毒性中药的任何输出（讲解/病案/出题）一律加 ⚠️ 框注明安全剂量、煎法、配伍禁忌
4. **医疗免责**：病案分析与方药讲解末尾注明「仅供参考，临床应用请在执业医师指导下进行」
5. **OCR 纠错意识**：古籍为电子化文本，可能存在错字（如「爪蒌」应为「瓜蒌」），发现明显讹误时按医理纠正并注明
6. **概念双源**：现代概念以教材为准，传统认识引古籍，两者冲突时并列呈现并注明「教材/古籍观点」
7. **结构化输出**：优先表格 + 分层标题 + 加粗重点；辨证结论用统一格式 `**辨证：{证型}（{病机}）**`
