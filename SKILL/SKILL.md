# 医学综合技能（yixue-zonghe）

## 概述

中西医双轨综合性医学技能，整合中医（经方思维、针灸经典、教材体系）与西医（现代医学教材）两大知识库，提供六大功能。**所有功能均支持中医与西医双轨，通过关键词「中医」/「西医」区分**。

**知识库构成：**
- **中医教材/**（711 部，随包装入）：10 部现代教材（UTF-8）+ 701 部古籍（GB18030）
- **西医教材/**（用户自行添加）：放入西医教材 txt 或 PDF，自动索引检索

完整分类索引见 `references/textbook-index.md`（中医）与 `references/textbook-index-西医.md`（西医）。

## 安装与教材路径

**skill 安装包内置中医教材（711 个 txt），西医教材需用户自行添加**：

1. 安装后目录形态：`<skill>/中医教材/*.txt` + `<skill>/西医教材/`（空，待添加）
2. 添加西医教材：将 txt 或 PDF 放入 `西医教材/`，运行 `python scripts/sync_new_materials.py --track 西医` 自动处理
3. 所有脚本默认 `--track 中医`，加 `--track 西医` 切换到西医教材目录
4. 若教材移往别处，可用 `--textbook-dir "路径"` 显式指定

## 多格式教材导入

支持将 **PDF / DOCX / DOC / TXT** 格式的教材自动转换为可检索的 txt 并归档。

### 支持的格式与处理方式

| 格式 | 处理方式 | OCR |
|------|---------|-----|
| **.pdf** | 文本层提取 → 扫描页整页 OCR → 内嵌图片 OCR（图表/解剖图） | 是 |
| **.docx** | python-docx 读取段落 + 表格 | 否（文本层） |
| **.doc** | Word COM 转 docx 后读取（需本机安装 Word） | 否 |
| **.txt** | 编码检测（UTF-8/GB18030）后转 UTF-8 归档 | 否 |

### 使用方式

```bash
cd {skill目录}/scripts

# 方式一：文件已放入教材目录，直接同步
python sync_new_materials.py --track 西医
python sync_new_materials.py --track 中医

# 方式二：从指定目录批量导入到教材目录后处理
python sync_new_materials.py --track 西医 --from "D:/待导入教材"

# 常用选项
python sync_new_materials.py --track 西医 --rebuild          # 强制重建所有 txt
python sync_new_materials.py --track 西医 --no-images-ocr    # 跳过 PDF 内嵌图片 OCR（更快）
python sync_new_materials.py --track 西医 --no-ocr           # 不做任何 OCR（仅文本层）
```

**处理结果**：每个源文件生成同名 `.txt`（UTF-8 编码），并自动重建对应体系的索引。

## 知识库检索（所有功能的基础）

### 检索脚本（必须使用，禁止凭记忆引原文）

```bash
cd {skill目录}/scripts

# 中医全库检索
python search_textbooks.py --track 中医 --keyword "胸痹" --context 6 --max-hits 20

# 西医检索（西医教材目录）
python search_textbooks.py --track 西医 --keyword "高血压" --context 6

# 按类目过滤（中医类目: 伤寒论,金匮要略,本草,针灸推拿,医经,温病瘟疫,医案医话,方书...）
python search_textbooks.py --track 中医 --keyword "栝蒌薤白" --category 金匮要略

# 指定文件精确检索
python search_textbooks.py --track 中医 --keyword "桂枝汤" --files "499-金匮要略方论.txt"

# 只看命中统计（快速定位素材最多的书）
python search_textbooks.py --track 中医 --keyword "小柴胡汤" --quiet
```

### 检索策略

1. **先教材定基线，再古籍补充深度**（中医）：概念/治法/方义以教材为准，经典原文与临床发挥查古籍
2. **关键词分层**：疾病名 → 证型/诊断名 → 方名/药名 → 理论术语，逐层缩小
3. **条文核对**：引用经典条文前必须用脚本核对原文，禁止凭记忆引用
4. **古籍文风适配**：古籍含「<篇名>」「<目录>」「属性：」等标记，脚本已自动清理为【篇】【目录】

### 素材批量提取（讲义/深度内容用）

```bash
# 中医：按系统提取（8 大系统: 肺系/心系/脾胃系/肝胆系/肾系/脑系/气血津液/肢体经络）
python extract_content.py --track 中医 --system 肺系 --output-dir 讲义素材

# 中医：深度模式 + 古籍经典文献
python extract_content.py --track 中医 --system 心系 --depth deep --ancient --category 伤寒论,金匮要略

# 西医：按关键词提取（西医教材无固定系统表，用 --keyword）
python extract_content.py --track 西医 --keyword "高血压,心力衰竭" --output-dir 西医讲义素材
```

## 功能一：医学学习

**流程：** 定位主题 → 判断中西医疗 → 知识库检索 → 结构化讲解 →（可选）关联延伸

**中医讲解结构：**

| 主题类型 | 讲解框架 | 主要检索源 |
|---------|---------|-----------|
| 基础理论（阴阳/五行/脏腑/气血津液） | 概念定义 → 脏腑功能 → 生理病理联系 → 临床意义 | 中医基础理论.txt + 医经类古籍 |
| 证候/辨证 | 概念 → 病因病机 → 临床表现 → 辨证要点 → 鉴别诊断 | 中医诊断学.txt |
| 疾病 | 定义 → 病因病机 → 证型分类 → 分证论治（表格）→ 转归预后 | 中医内科学.txt + 伤寒金匮 |
| 经典条文 | 原文 → 逐句释义 → 病机分析 → 方证 → 类证鉴别 | 伤寒论/金匮要略类古籍 |

**西医讲解结构：**

| 主题类型 | 讲解框架 | 主要检索源 |
|---------|---------|-----------|
| 解剖/生理 | 结构 → 功能 → 调节机制 → 临床意义 | 西医教材/系统解剖学/生理学 |
| 病理/发病机制 | 病因 → 发病机制 → 病理变化 → 临床表现 | 西医教材/病理学 |
| 疾病 | 定义 → 流行病学 → 病因病理 → 临床表现 → 辅助检查 → 诊断标准 → 鉴别诊断 → 治疗（药物/手术/其他）→ 预后 | 西医教材/内科学/外科学等 |
| 药物 | 分类 → 作用机制 → 适应证 → 用法用量 → 不良反应 → 禁忌 | 西医教材/药理学 |

**风格规则：**
- 结构化输出：表格 + 加粗重点 + 分层小标题
- 中医经方内容融入倪师思维：先阴阳大局、再抓主证、条文卡片佐证
- 西医内容强调循证医学依据、指南推荐
- 概念解释配 1-2 个临床实例

**① 需求确认：** 体系（中医/西医）、讲义主题（系统/疾病/方剂/药物……）、深度（基础/标准/深度）、篇幅。


**⑥ 质量检查：** 执行 `python scripts/validate_html.py`，并按 `references/quality-checklist.md` 核对。

## 功能三：病案/病例分析

### 中医病案分析（关键词含「中医」「辨证」「病案」）

**必读 `references/case-analysis.md` 后执行。** 核心为六步法：

四诊信息提取（表格，未载项标「未载」）→ 辨证分析（八纲+脏腑+病性，标准格式 `**辨证：{证型}（{病机}）**`）→ 病因病机推演（箭头链条图）→ 治法确立 → 方药拟定（君臣佐使+加减+调护）→ 经典文献对照（检索脚本查条文佐证）

**红线：** 不得臆造四诊信息；证型必须用标准名称；经典引用必须核对；不确定处写「本案亦可从 X 证考虑，鉴别点在于 Y」。

### 西医病例分析（关键词含「西医」「诊断」「病例」）

**核心为诊断思路六步法：**

主诉与现病史整理 → 既往史/个人史/家族史 → 体格检查与辅助检查 → 初步诊断与鉴别诊断（列出 2-3 个可能诊断及支持/不支持点）→ 进一步检查计划 → 治疗方案（药物/手术/支持治疗）+ 随访

**输出结构：**
```
**初步诊断：{主要诊断}**
**诊断依据：** {病史+查体+辅助检查要点}
**鉴别诊断：**
  1. {鉴别诊断1}：支持点…… 不支持点……
  2. {鉴别诊断2}：……
**治疗方案：** {药物（剂量+疗程）/ 手术指征 / 支持治疗}
```

**红线：** 不得臆造检查结果；诊断需有依据；药物剂量与疗程须规范；不确定处写「需进一步行 X 检查以明确」。

## 功能五：中药/西药处方讲解

### 中药处方讲解（关键词含「中医」「方剂」「中药」「方义」）

**必读 `references/prescription-guide.md` 后执行。** 核心为五层讲解：

方名释义 → 出处与经典条文（经方条文卡片必出）→ 组方结构（君臣佐使表）→ 逐味药讲解（性味归经+功效+本方作用）→ 临床运用（辨证眼目+加减+类方鉴别+禁忌）

**剂量规则：** 原方剂量与现代常用量双列（一两≈3g 教材通行）。**毒性药物（附子、细辛、半夏、乌头、甘遂、朱砂、马钱子等）必须加 ⚠️ 警示框**：剂量上限、煎法（先煎久煎）、十八反十九畏。

### 西药讲解（关键词含「西医」「西药」「药物」「抗生素」「降压药」等）

**核心为六层讲解：**

药物分类 → 作用机制 → 适应证 → 用法用量（剂量+频次+疗程）→ 不良反应 → 禁忌与相互作用 → 临床注意事项

**输出结构：**
```
{药名}（{英文名}·{分类}）
作用机制：{作用靶点/通路}
适应证：{疾病/症状}
用法用量：{剂量范围 + 频次 + 疗程}
不良反应：{常见/严重不良反应}
禁忌：{绝对/相对禁忌}
药物相互作用：{重要相互作用}
⚠️ 注意事项：{特殊人群（孕妇/儿童/肝肾不全）调整、监测指标}
```

**红线：** 处方药须注明「须在医师指导下使用」；特殊人群剂量须调整说明；不得替代医嘱。

## 功能六：模拟题出题（中西医通用）

**必读 `references/quiz-guide.md` 后执行。** 核心为四步流程：

确认需求（**体系+大纲+题数+总分四项必问**，缺一不可；默认中医·执业医师风格·10 题·100 分）→ 知识库取材（**中医取自中医教材，西医取自西医教材，题干与答案必须有出处**）→ 命题写入 exam.json → 用 `scripts/build_exam_html.py` 生成交付物

**体系区分：**
- 中医题：辨证论治、方剂组成、腧穴主治、经典条文等
- 西医题：诊断标准、药物机制、辅助检查、治疗指南等

**标准交付物：**
```bash
python scripts/build_exam_html.py --exam exam.json --output-dir 试卷输出 --name "{试卷名}"
```

1. **交互式 HTML 试卷（必出）**——客观题自动判分，主观题关键词批改，成绩卡显示
2. **答案卷 HTML（必出）**——每题附答案、解析、知识库出处

质量自检（分值合计、难度分布 3:5:2、答案核对）通过后再交付。

## 通用规则（所有功能必须遵守）

1. **出处至上**：所有经典条文、方剂组成、药物剂量、诊断标准引用前，先用检索脚本核对；禁止凭记忆引用
2. **编码注意**：中医现代教材 UTF-8、中医古籍 GB18030——直接读文件时必须使用 `scripts/text_utils.py` 的 `read_text()`
3. **中医毒性药物警示**：涉及毒性中药的任何输出一律加 ⚠️ 框注明安全剂量、煎法、配伍禁忌
4. **西医处方药警示**：涉及处方药的输出注明「须在医师指导下使用」，特殊人群剂量须说明
5. **医疗免责**：病案/病例分析与方药讲解末尾注明「仅供参考，临床应用请在执业医师指导下进行」
6. **中西医分明**：中医用辨证/证型/方剂/经络术语；西医用诊断/病因病理/药物机制术语；不得混用
7. **概念双源**：中医以教材为准+古籍补充；西医以教材/指南为准；两者对同一疾病的认识可并列呈现
8. **结构化输出**：优先表格 + 分层标题 + 加粗重点
